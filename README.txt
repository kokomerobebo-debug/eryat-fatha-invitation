ERYAT FATHA — ANIMATED ONE PAGE INVITATION

OPEN: Double-click index.html in Chrome / Edge. No installation or build required.

EDIT:
  index.html     Text, event details and navigation
  style.css      Colors, layout, floral sides, animations and image sizes
  script.js      Click-to-open envelope, scroll animation, car motion, countdown
  assets/        Each decorative image as a separate PNG

The envelope and heart are the two original uploaded transparent PNG images.
The flowers extend along the entire document, including the footer.
Countdown is calculated to December 26 2026 at midnight Cairo time (+02:00).
Internet is only needed to load the decorative Google Fonts.

To publish: upload all files and the assets folder together to any static web host, e.g. GitHub Pages.
